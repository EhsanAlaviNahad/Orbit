Keyboard first

What you can do from the keyboard

Orbit scans only the focused window, using macOS Accessibility for native controls and optional on-device Vision OCR where the accessibility tree is sparse.

Click, double-click, right-click Return, Option-Return, Shift-Return
Arrange the window left, right, top, bottom, center, fill, maximize, full screen
Scroll with hints open Option-Up / Option-Down, 0.5× to 3×
System commands restart, shutdown, sleep — each needs two Returns

This is a simulator running in your browser, not Orbit itself. No benchmark of Orbit against a mouse exists, so this page will not quote one. Pointing

ID = log2(1 + A / W)

MT = 94.21 ms + 173.64 ms/bit × ID

  • Wobbrock, Cutrell, Harada & MacKenzie, CHI 2008: 16 participants, one optical mouse, acceleration off.
  • 94.21 ms and 173.64 ms/bit are the average coefficients that study reports for mouse pointing, fitted with MacKenzie's Shannon formulation.
  • MT is movement time to the target. It is a model of a pointing population, not a measurement of you.

Typing

ms per character = 60 000 ÷ (5 × wpm)

Orbit = (characters + 2) × per character + 15 ms

  • The +2 charges one keystroke for ⌘E and one for Return.
  • The 15 ms is Orbit's own cost, measured on macOS 27.2 by Scripts/bench-scan.sh: 3.6–7.8 ms to read a 14-element Finder window plus 6.7–7.8 ms to merge its targets. A bigger window costs more, so run the script on your own Mac.

Not modelled, in either direction: the click itself, finding the control with your eyes before moving to it, learning what a control is called, corrections after a miss, and the fact that a pointer has to travel back. The pointing figure also assumes one direct movement, at the speed-accuracy balance the study's participants chose.

One command

Install

Terminal 
curl -fsSL https://raw.githubusercontent.com/EhsanAlaviNahad/Orbit/main/Scripts/install.sh | bash

Requires an Apple silicon Mac on macOS 27 or newer, plus the Swift 6.2 command line tools. Orbit then lives only in the menu bar; grant it Accessibility on first use. The script replaces ~/Applications/Orbit.app and removes ~/Applications/Eclick.app only if that bundle carries Orbit's old identifier — read Scripts/install-app.sh, which is where that happens, before you pipe it into a shell.

On device

Privacy

No network calls, no telemetry, no accounts. Screen content, element names, and everything you type stay in memory on your Mac. OCR runs on-device through Vision.
