What you can do from the keyboard

Orbit scans only the focused window, using macOS Accessibility for native controls and optional on-device Vision OCR where the accessibility tree is sparse.

Click, double-click, right-clickReturn, Option-Return, Shift-Return
Arrange the windowleft, right, center, fill, maximize, full screen
Scroll with hints openOption-Up / Option-Down, 0.5× to 3×
System commandsrestart, shutdown, sleep — each needs two Returns

This is a simulator running in your browser, not Orbit itself: it uses the same normalisation and hint-ranking rules as Core.swift, over a fixed list of TextEdit controls. Orbit needs a real macOS window to scan.

Install

curl -fsSL https://raw.githubusercontent.com/EhsanAlaviNahad/Orbit/main/Scripts/install.sh | bash

Requires an Apple silicon Mac on macOS 27 or newer, plus the Swift 6.2 command line tools. Orbit then lives only in the menu bar; grant it Accessibility on first use.

Privacy

No network calls, no telemetry, no accounts. Screen content, element names, and everything you type stay in memory on your Mac. OCR runs on-device through Vision.
